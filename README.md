# IHSVideoGameDesign

**ARCHIVED PROJECT** — This game is **broken and no longer supported**. This repository is maintained for historical/educational purposes only. Do not expect the game to run or function properly.

A Unity game project created for the Issaquah High School Video Game Design course.

## Overview

This is an educational game development project from high school, exploring game design and development with Unity. The codebase and project structure may have compatibility issues with modern versions of Unity and are not actively maintained. This was our first experience with Unity, so there will be a lot of mistakes involving our code.

## Getting Started (For Educational/Reference Use Only)

### Prerequisites

- **Unity** (earlier version from when project was active)
- **Visual Studio** or another C# IDE
- Git (for cloning)

### Attempting to Run

**Note:** Running this project may result in compilation errors or runtime failures.

1. Clone the repository:
   ```bash
   git clone https://github.com/ArjunPervaje/IHSVideoGameDesign.git
   cd IHSVideoGameDesign
   ```

2. Open in Unity:
   - Launch Unity Hub
   - Click "Open Project"
   - Select the `IHSVideoGameDesign` folder
   - Allow Unity to attempt importing assets

3. Attempt to run:
   - You may encounter script compilation errors
   - Missing asset references are likely
   - The game probably won't play as intended
